This repository organizes practical skills and toolsets acquired during professional QA Manual training at **Beetroot Academy / Helvetas Ukraine**.

It contains samples of test documentation, test design techniques, client-server architecture analysis, and API testing results.

---

##  Skills & Technical Stack

* **Testing Methodologies:** Manual Testing (Functional, UI/UX, Regression, Smoke), Test Design Techniques (Equivalence Partitioning, Boundary Value Analysis).
* **Test Management:** Working with TestRail and Jira; complete cycle of bug reporting and tracking.
* **Web & API:** Web interface structure analysis (HTML/CSS, DevTools), API Testing (Postman, SoapUI, JSON, REST).
* **Mobile Testing:** Basic principles of mobile application testing (Android/iOS).
* **Version Control:** Git, GitHub, Command Line Interface (CLI).
