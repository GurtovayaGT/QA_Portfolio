## English Summary

Project Overview:  
This repository contains Homework #1 for the Software Testing and QA course. The assignment demonstrates fundamental software testing principles, domain analysis, and test documentation practices using ISTQB guidelines.

Key Scope & Topics Covered:

Verification vs Validation: Theoretical concepts explained through practical scenarios and real-world analogies — including a hands-on example with a ballpoint pen showing how a fully verified product can still fail validation in real-world conditions.

Types of IT Companies: Comparative analysis of 6 company business models (Product, Outsourcing, Outstaffing, Startup, IT Academy, Recruiting Agency) from an employee perspective, covering pros and cons for each.

Domain Expertise: Application of prior management experience (cosmetics distribution and legal/contractual analysis) to quality assurance principles — demonstrating how cross-industry knowledge strengthens QA thinking.

Test Reporting: A practical test report for a physical object (a ballpoint pen) with defined Expected Results, Actual Results, Status, Severity, and Priority — covering functional, non-functional, stress, security, and regression testing types. 4 defects identified, including a Critical severity ink leakage bug.

ISTQB Principles: In-depth analysis of two key ISTQB principles (Early Testing and Context-Dependent Testing) illustrated with real-world examples from legal contract review and B2B cosmetics distribution.

## Ключові навички, продемонстровані в роботі

Тест-дизайнування та звітність: Складання тестових репортів у форматі, наближеному до реального (**Expected Result**, **Actual Result**, **Severity**, **Priority**), з виявленням 4 дефектів різної критичності.

Глибоке розуміння QA-концепцій: Чітке розмежування **Verification** та **Validation** із практичними прикладами, що демонструють різницю між відповідністю специфікації та реальними потребами користувача.

Системне мислення: Застосування принципів раннього тестування (**Early Testing**) та регресійного тестування на прикладі фізичного об'єкта — демонстрація того, як ці концепції працюють поза межами IT.

Переносний досвід (Domain Expertise): Використання юридичного та менеджерського досвіду з дистрибуції косметики для ілюстрації принципів ISTQB — показує здатність застосовувати знання з інших галузей у QA-контексті.
